# Navyam Atelier & Co

Multidisciplinary architecture and spatial design studio portfolio website.

## Live Preview
- Original deployment: https://nac-lilac.vercel.app

## Getting Started

You can run the project locally with any static HTTP server:

### Option 1: Python
```bash
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Node / npm
```bash
npm run dev
```

## Structure
- `index.html` - Main entry point with full routing and page views (#intro, #home, #projects, #studio, #contact)
- `style.css` - Custom architectural design system, styling, animations, and typography tokens
- `app.js` - Client router, state management, project modal viewer, and interactive gallery lightbox
- `SoulFoods/` - Assets for The Soul Foods retail project
- `Vega/` - Assets for Vega Charge sustainable villa compound
- `GreenTerraces/` - Assets for Green Terraces luxury residence interiors
- `ThrdspaceStudio/` - Assets for Thrdspace Studio creative pavilion
- `studio-hero.jpg` - High-res studio atelier banner
